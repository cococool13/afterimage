What do I need?
Windows 11, an NVIDIA GPU, and .NET 8 Desktop. Build on the Windows PC with the command in the repo.
Why is my clip black?
Exclusive fullscreen often captures black. Switch the game to borderless windowed.

If the game is running as Administrator, Afterimage must too.
